# JSContact Card 2.0 core

This contract provides a deliberately bounded JSContact Card representation
for interoperable contact records. It follows JSContact 2.0, including the
optional `uid` introduced by RFC 9982.

The profile accepts a strict subset of JSContact properties. It is not an
official IETF JSON Schema and does not claim to validate every JSContact
extension or conditional semantic rule.
