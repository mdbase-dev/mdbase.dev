# View

A view record stores shared query scope and one or more stable named views.
Tools that support saved views discover these records through the `mdbase.view`
contract and run each named view as an ordinary query.

This type belongs to your collection once installed. You can rename fields or
change how records are matched, as long as the `implements` mapping still
points each contract field at the right frontmatter field.
