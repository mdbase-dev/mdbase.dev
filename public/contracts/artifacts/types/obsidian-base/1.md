# Obsidian Base

Makes `.base` files discoverable as saved views through the `obsidian.base`
contract. It takes effect when the collection lists `base` in
`settings.record_extensions`; narrow the `path_glob` to the folders that hold
your Bases. Edit Bases with whole-document replacement so Obsidian's comments
and layout survive.
