## Keyboard shortcuts {#shortcuts}

On a Mac, use <kbd>⌘</kbd> in place of <kbd>Ctrl</kbd>, except for <kbd>Ctrl</kbd> <kbd>Tab</kbd>. Single-key shortcuts such as <kbd>H</kbd> and <kbd>/</kbd> do nothing while you are typing in a field.

| Keys | Action |
| --- | --- |
| <kbd>Ctrl K</kbd> | Search sources and run commands |
| <kbd>Ctrl Shift F</kbd> | Filter sources in the sidebar |
| <kbd>/</kbd> | Search the library view, or the sidebar elsewhere |
| <kbd>H</kbd> | Highlight the selected text |
| <kbd>C</kbd> | Comment on the selected text |
| <kbd>Esc</kbd> | Dismiss the selection toolbar, or leave reading mode |
| <kbd>Ctrl .</kbd> | Enter or leave reading mode |
| <kbd>Ctrl &#92;</kbd> | Show or hide the left sidebar |
| <kbd>Ctrl Shift &#92;</kbd> | Show or hide the right sidebar |
| <kbd>Ctrl Tab / Ctrl Shift Tab</kbd> | Next or previous tab |
| <kbd>Ctrl Shift T</kbd> | Reopen the last closed tab |
| <kbd>Alt ← / Alt →</kbd> | Back or forward |
| <kbd>F6</kbd> | Move focus to the next pane |
| <kbd>Ctrl Enter</kbd> | Open the selected sidebar source beside the current one |

For the browser extension's shortcuts, see [Browser extension](/apps/reader/extension/#highlights). Chrome can change extension shortcuts at `chrome://extensions/shortcuts`.

## Command palette {#palette}

<kbd>Ctrl</kbd> <kbd>K</kbd> opens the command palette. Type part of a source title or author to open it, or a command name to run it. Commands include opening the library, adding or importing sources, switching between open tabs, opening a source's note, annotations or citation, arranging and resetting panes, exporting, bookmarking and changing the theme. The **Reset pane arrangement** command keeps your tabs open; **Import a library…** opens the import flow in a new tab.

## Text and display {#display}

Open **Text and display** in the header. These settings are stored in this browser. Light, dark and system themes are also available from the command palette. Reading preferences change reflowable documents; PDFs retain their page layout.

| Setting | Effect |
| --- | --- |
| Text size | Larger or smaller text for EPUBs and saved web pages. |
| Typeface | Serif or sans serif. |
| Line length | Narrow or standard. |
| Density | Comfortable or compact lists and tables. |
| Sidebar while reading | Keep the sidebar open or hide it while a document is focused. |
| Selecting text | Show actions, or highlight at once. |
