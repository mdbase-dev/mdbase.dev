## Keyboard shortcuts {#shortcuts}

On a Mac, use <kbd>⌘</kbd> in place of <kbd>Ctrl</kbd>. Press <kbd>?</kbd> anywhere outside a text field to see the guide in the Editor.

| Keys | Action |
| --- | --- |
| <kbd>Ctrl P</kbd> | Quick open |
| <kbd>Ctrl K</kbd> | Quick open, outside the note text |
| <kbd>&gt;</kbd> | Actions, typed at the start of quick open |
| <kbd>Ctrl Shift N</kbd> | New note |
| <kbd>Ctrl Enter</kbd> | Create the note being composed |
| <kbd>Ctrl Shift L</kbd> | Show or hide the notes sidebar |
| <kbd>↑ / ↓</kbd> | Move through the note list |
| <kbd>Alt J / Alt K</kbd> | Next or previous note |
| <kbd>Alt ← / Alt →</kbd> | Back or forward through opened notes |
| <kbd>Ctrl F</kbd> | Find in note |
| <kbd>Ctrl B / Ctrl I</kbd> | Bold or italic |
| <kbd>Ctrl Shift C</kbd> | Inline code |
| <kbd>Ctrl K</kbd> | Add a link, in the note text |
| <kbd>Tab / Shift Tab</kbd> | Indent or outdent a list item |
| <kbd>/</kbd> | Markdown commands, at the start of a line |
| <kbd>[[</kbd> | Link to a note or file |
| <kbd>@</kbd> | Link to a note, optionally filtered by type |
| <kbd>?</kbd> | Show the shortcut guide |
| <kbd>Esc</kbd> | Close quick open or the shortcut guide |

## Editor settings {#settings}

Open **Settings** from the collection rail. These preferences are stored in this browser only.

| Setting | Effect |
| --- | --- |
| Color theme | Follow the system appearance, or keep a light or dark theme in this browser. |
| Text size | Compact, Comfortable or Large note text, without changing the rest of the interface. |
| Wrap long lines | Keep Markdown within the writing width. On by default. |
| Quiet Markdown | Soften punctuation away from the active line and make tasks checkable. On by default. |
| Vim key bindings | Use normal, insert, visual and command modes in the note editor. Off by default. |

## Collection settings {#collection}

Settings also shows the open collection: its ID, the specification version it uses, its types folder, the frontmatter keys that declare a type, its validation level, and the operations the Editor is approved for. **Forget from this browser** removes the collection from the Editor without changing its files.
